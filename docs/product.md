# ChannelHunter — Product

**Аналитика. Реклама. Рост.**

SaaS-платформа для аналитики Telegram-каналов, поиска рекламных площадок,
управления кампаниями и контроля эффективности рекламы.

## 1. Кому и зачем

| Аудитория | Задачи | Что получает |
| --------- | ------ | ------------ |
| Владелец канала | Рост и вовлечённость, продажа рекламы | Динамика подписчиков и охватов, ERR, оценка рекламных слотов |
| Рекламодатель | Выбор площадок, контроль бюджета | Сравнение каналов, CPM/CPC/CPF, эффективность размещений |
| Агентство | Много клиентов и каналов | Рабочие пространства с ролями, отчёты, история |

Один пользователь может совмещать роли: аккаунт один, роль определяется внутри
рабочего пространства (`owner`, `admin`, `analyst`, `viewer`).

## 2. Интерфейсы

1. **Telegram-бот — основной интерфейс первой версии.**
2. **Telegram Mini App** — React + TypeScript, второй этап. Backend уже
   спроектирован под него: единый REST API `/api/v1`, аутентификация по
   подписанному `initData`, контракт в `shared/api/openapi.yaml`.
3. Никакого «второго приложения»: бот и Mini App — два клиента одного backend.

## 3. Главный сценарий

```
/start → регистрация (идемпотентно) → workspace → главное меню
   │
   ├─ Мои каналы → добавить (@username, t.me/…, ID, CSV/XLSX, свой канал)
   │                   → карточка: что известно, что нет и почему
   ├─ Аналитика → показатели за период, динамика, достоверность источника
   ├─ Сравнение → 2–10 каналов, сортировка по любому показателю
   ├─ Реклама → кампании: бюджет, размещение, метрики, эффективность
   ├─ Отчёты → сводка в Telegram и CSV
   ├─ Тариф → лимиты текущего плана и апгрейд
   └─ Настройки → уведомления, язык, участники
```

## 4. Честность данных — ключевое продуктовое правило

Telegram Bot API **не отдаёт** статистику произвольных чужих каналов. Поэтому:

* Для собственных каналов (бот — администратор) данные `verified`.
* Для публичных каналов — только через легальный внешний провайдер с API
  (`estimated`) либо из загруженного пользователем файла (`unverified`).
* Если показатель недоступен — показываем «нет данных», а не `0`.
* В карточке канала всегда видно: источник, дату получения, период и статус
  достоверности.
* Неофициальный скрейпинг не используется как основа продукта.

Это делает отчёты защищаемыми перед рекламодателем: каждое число имеет
происхождение.

## 5. Показатели

Subscribers · Growth · Views · Average Views · ERR · Post Frequency · CPM · CPC ·
CPF — с указанием периода и методики. Формулы и обработка отсутствующих данных:
см. [architecture.md § 9](architecture.md#9-analytics-formulas).

## 6. Тарифы

| | FREE | PRO | BUSINESS |
| --- | --- | --- | --- |
| Каналов | 3 | 30 | 150 |
| История | 7 дней | 90 дней | 365 дней |
| Участники workspace | 1 | 3 | 5 |
| Кампании | 3 | 50 | 500 |
| Сравнение каналов | — | ✓ | ✓ |
| CSV-отчёты | — | ✓ | ✓ |
| Расширенная аналитика | — | — | ✓ |
| Мониторинг | 12 ч | 3 ч | 1 ч |
| Цена (по умолчанию) | 0 ₽ | 1 490 ₽/мес | 4 990 ₽/мес |

Цены и лимиты — данные в таблице `plans`, а не константы в коде. Проверка
лимитов выполняется только на backend.

Оплата: архитектура адаптеров (`PaymentProvider`) готова, фиктивная оплата не
реализуется. Для цифровых функций внутри Telegram действуют правила Telegram
Stars — провайдер подключается отдельным адаптером с проверкой подписи вебхука и
идемпотентностью.

## 7. Уведомления

* Заметное падение охватов.
* Резкий рост или отток подписчиков.
* Завершение рекламной кампании.
* Готовность отчёта.
* Изменение показателей отслеживаемого канала.

Дубли исключены на уровне БД (`notifications.dedupe_key` + уникальный индекс).

## 8. Что НЕ входит в 1.0

* Скрейпинг и обход ограничений Telegram.
* Гарантия данных по любым каналам — только по доступным источникам.
* PDF-отчёты (следующий этап после CSV + Telegram).
* Ad Marketplace и комиссия со сделок.

## 9. Метрики успеха продукта

* Доля каналов с `verified`-данными (качество источника).
* Активность: каналов на workspace, кампаний в месяц.
* Удержание: возврат в бота на 7/30 день.
* Конверсия FREE → PRO после исчерпания лимита каналов.
